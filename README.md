## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- A code editor (VS Code, Sublime Text, etc.)
- Basic understanding of HTML and CSS (helpful but not required)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/48vineet/JavaScript-Learning.git
   cd JavaScript-Learning
   ```

2. **Open in your browser:**
   - Simply open `index.html` in your preferred web browser, or
   - Use a local server:
     ```bash
     python -m http.server 8000
     # or with Node.js
     npx http-server
     ```

3. **Open in your editor:**
   - Open the repository folder in your code editor to explore the files

## 💻 How to Use

1. **Browse the Examples:**
   - Navigate through different topic folders
   - Each file contains well-commented code examples

2. **Experiment:**
   - Open files in your browser
   - Use DevTools (F12) to inspect and debug
   - Modify code to understand how it works

3. **Practice:**
   - Work through exercises
   - Try to solve problems before looking at solutions
   - Build mini-projects to apply your knowledge

4. **Learn by Doing:**
   - Read the comments
   - Execute the code
   - Experiment with variations
   - Build your own projects
